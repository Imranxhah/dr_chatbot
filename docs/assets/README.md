# Cover artwork

## Generation prompt

Use case: stylized-concept. Create one sophisticated wide 3:1 GitHub project cover. Exact title text "DR. CHATBOT" and subtitle "Flutter + Gemini exploration". Midnight navy background, restrained periwinkle and cyan accents, editorial typography on left. Right side shows sculptural translucent conversation bubbles and small interconnected light nodes, an abstract metaphor for conversational software. Elegant soft 3D matte rendering, generous whitespace, beautifully finished professional developer portfolio artwork. No medical diagnoses, no doctor or patient, no hospital logo, no screenshot, no metrics, no watermark.
